# Tpei 的桌面小工具

两个用 HTA（HTML Application）写的 Windows 桌面小程序，双击就能跑，不用装任何东西。

## 里面有什么

| 目录 | 作品 | 说明 |
| --- | --- | --- |
| `贪吃蛇/` | Tpei 的贪吃蛇（`.hta` 桌面版） | 方向键控制，吃豆子变长，撞墙或撞自己就结束；带最高分记录 |
| `贪吃蛇/贪吃蛇网页版.html` | 同一个游戏的浏览器版 | 双击用浏览器打开就能玩，Windows / macOS / Linux 都行 |
| `聊天工作室/` | Tpei 聊天机器人工作室 | 可以自定义多个机器人的性格、自动回复规则、定时发言；也支持接入大模型 API 做真聊天 |

## 怎么运行

1. 把这个仓库下载到本地（Code → Download ZIP，或用 git 克隆）
2. **桌面版**：进对应目录，双击 `.hta` 文件即可，不需要安装、不需要联网
3. **网页版**：双击 `贪吃蛇网页版.html`，用任意现代浏览器打开
4. 只有聊天工作室要联网：想接大模型的话，在界面里填自己的接口地址和 API Key；不填也能玩，走本地规则回复

## 隐私说明（重要）

- 这两个程序**不收集、不上传任何数据**，所有东西都只存在你自己电脑里
- 聊天工作室会把聊天记录和 API Key 存在程序旁边的 `tpei_botdata.json` 里，这个文件已经在 `.gitignore` 里被排除，不会进仓库
- 建议你也别手动把这个 json 文件发出去，里面有你的私人对话

## 开源前的自检（已做）

发布前对全部源码做过一遍排查，结论：

- 代码里**没有任何**本机路径、邮箱、手机号、身份证、IP 地址
- **没有写死的密钥**：聊天工作室的 API Key 是运行时由使用者自己填的，只存在本机
- 网络行为只有一处，且是可选的：聊天工作室在你主动开启 AI 后，才会把你的消息发到你填的那个接口地址；默认关闭、默认不联网
- 本地数据文件 `tpei_botdata.json`（聊天记录 + 密钥）已用 `.gitignore` 排除，不会进仓库

## 已知限制

- 只能在 **Windows** 上跑：HTA 依赖系统自带的 `mshta.exe`（IE 内核），macOS / Linux 不支持
- 部分杀毒软件会对 HTA 弹提示，因为它权限比较高；自己下载自己那份就不会有问题
- 聊天工作室默认不填 API Key 也能玩，走的是本地规则回复；填了 Key 才会真去调大模型
